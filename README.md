# Options-Project
This Python program is a comprehensive options-trading analysis and reporting tool that automates the entire process of retrieving live market data, performing quantitative modeling, and producing professional-grade analytics. When the user enters a stock ticker, the program connects to Yahoo Finance to retrieve the current price, option chain data, and the nearest available expiration dates. It then calculates option prices using the Black–Scholes model and derives all prominent Greeks—delta, gamma, vega, theta, and rho—to quantify how the option’s value responds to changes in market conditions.

Beyond introductory pricing, the program estimates both realized volatility (from historical returns) and implied volatility (by inverting the market price of the option), producing an “IV30” measure that reflects the market’s short-term expectations. It also computes the expected stock price move using volatility and straddle pricing, helping the user anticipate the likely trading range before expiration. To enrich the market view, the program includes technical indicators such as RSI and MACD as well as put/call ratios based on open interest and trading volume.

Once all metrics are calculated, the tool simulates payoff profiles for key strategies—long call, long put, straddle, and covered call—across a range of future stock prices. It visualizes these as payoff charts and also shows how the option’s theoretical price varies with volatility. All results are consolidated into a single timestamped Excel report containing three sheets (Option Summary, Payoff Table, and Volatility Impact) along with PNG charts saved in the working folder.
